# 增长质量与口径

## 为什么需要这一层

「增速 40%」不是一个数，而是一组口径：

- 营收 / 毛利 / 归母 / 扣非 / 经调整？
- 单季 / 累计 / TTM？
- 内生 / 并表 / 低基数 / 非经常 / 公允价值 / 周期涨价？

口径不统一，六条标准就会得出互相矛盾的结论。

需要拆老业务/新业务、境内/境外、产品结构或量价时，配合 `analysis-blocks.md` 的增长拆解块；先拆结构，再统一口径。

## 口径决议顺序

### 1. 先确定指标

| 指标 | 用途 | 注意 |
|---|---|---|
| 营收增速 | 判断主营需求 | 作者「主营增速 <40% 不买」的首选口径 |
| 归母净利增速 | 判断股东利润 | 可能含非经常性损益 |
| 扣非净利增速 | 判断经营利润 | 优先于归母 |
| 经调整净利 | 跨境/生物医药常用 | 必须说明调整项 |
| 单季增速 | 判断最新动能 | 优先于累计，避免被前几季平均 |
| 累计增速 | 判断年度趋势 | 不能替代单季 |

**默认规则**：先看单季营收与扣非；再看累计；归母只作辅助。若用户只给累计，必须标 `累计口径`。

### 2. 再拆增长来源

| 标签 | 识别信号 | 处理 |
|---|---|---|
| `内生` | 新品、新客户、新产能、份额提升 | 可正常评分 |
| `并表` | 收购、重组、合并范围变化 | 用 pro forma/可比口径；不能直接当内生 |
| `低基数` | 去年同期亏损/微利/一次性低点 | 看绝对额与历史峰值，不只看百分比 |
| `非经常` | 出售资产、政府补助、投资收益 | 看扣非；非经常占净利高则降档 |
| `公允价值` | 生物资产、投资性房地产、金融资产重估 | 标 `账面利润`；主业单独看 |
| `周期涨价` | 产品涨价、价差修复、行业回暖 | 拆量/价/毛利率；判断可持续性 |
| `单一客户` | 前五大客户占比高 | 标客户集中风险 |
| `应收账款/存货` | 增速高于营收、周转变慢 | 标现金流/减值风险 |

### 3. 再看利润与现金流匹配

- 经营现金流 / 净利：长期低于 0.7 要警惕。
- 应收账款增速 > 营收增速：可能在放松信用换增长。
- 存货增速 > 营收增速：可能在备货或滞销。
- 毛利率上升但经营现金流下降：利润质量存疑。

### 4. 再看环比动能

- 单季营收环比、单季扣非环比是否仍在加速。
- 毛利率环比是否稳定或上升。
- 若同比高增但环比停滞，标 `动能减速`，至少降为「只跟踪」。

## 判定表

| 情况 | 判定 | 说明 |
|---|---|---|
| 单季营收 ≥40%，扣非 ≥40%，环比向上 | `高质量增长` | 可进入六条标准 |
| 营收 <40%，扣非 ≥40% | `营收未达标` | 按作者「主营 <40% 不买」，硬伤 |
| 营收 ≥40%，扣非 <40% | `利润未跟上` | 可能投入期，需定性 |
| 归母高增、扣非低增 | `非经常驱动` | 降档，看扣非 |
| 并表带来高增 | `并表驱动` | 用可比口径；不能直接评高分 |
| 低基数导致倍数增长 | `低基数` | 看绝对额与历史峰值 |
| 公允价值贡献主要利润 | `账面利润` | 主业单独评分 |
| 涨价周期贡献主要增长 | `周期修复` | 不是永久成长；看量价与供给 |
| 营收/利润高增但现金流恶化 | `增长质量存疑` | 降档 |

## 经典案例（仅用于演示口径）

| 公司 | 表面数字 | 口径问题 | 结论 |
|---|---|---|---|
| 松发股份 | 2026 前三季营收 +221%、净利 +425% | 恒力重工并表/重组 | 标 `并表驱动`；看 pro forma、订单、负债 |
| 药明康德 | 营收 +38.6%、归母 +60.6%、扣非 +73% | 营收差一点；Q3 有非经常性收益 | 标 `接近`；用扣非/持续经营口径 |
| 拓荆科技 | 营收 +23.7%、净利 +337%，Q3 营收 +1.8% | 利润强、营收不达标 | 按主营口径 `硬伤` |
| 昭衍新药 | H1 净利 +885%–1377% | 实验猴公允价值；主业亏损/微利 | 标 `账面利润`；主业不达标 |
| 兆易创新 | 营收 +197%、净利 +922% | 存储周期 + 公允价值 18.78 亿 | 标 `周期+公允价值`；看扣非与环比 |
| 中际旭创 | 营收 +178%、净利 +212% | 内生、毛利率升、现金流升 | `高质量增长`；但趋势/估值另判 |

## 输出格式

每家公司至少输出：

```text
[公司] 口径：单季/累计；营收 X%；扣非 Y%；归母 Z%
增长质量：内生/并表/低基数/非经常/公允价值/周期涨价
环比：营收 QoQ X%；扣非 QoQ Y%
现金流：OCF/净利 = X
判定：高质量增长 / 营收未达标 / 非经常驱动 / 并表驱动 / 账面利润 / 周期修复 / 增长质量存疑
```

## 规则

- 不允许用「净利高增」替代「营收/主营高增」。
- 不允许用「并表/低基数/公允价值」直接给高 growth 评分。
- 不允许在同一张比较表里混用口径。
- 口径无法统一时，输出 `口径分歧`，不要强行排名。
