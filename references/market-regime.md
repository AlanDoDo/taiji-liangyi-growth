# 市场环境与拥挤度

## 定位

市场环境只决定**节奏和仓位**，不决定公司质量。

不要用「大盘不好」否定一家好公司，也不要用「公司很好」忽略市场正在杀估值。

## 需要观察的五个变量

| 变量 | 看什么 | 作用 |
|---|---|---|
| 指数趋势 | 主要指数在 20/60/120 日均线上方还是下方 | 判断整体风险偏好 |
| 风格 | 成长/价值、大小盘、红利/科技 | 判断资金在哪一边 |
| 拥挤度 | 公募持仓、抱团度、换手率、融资余额、成交占比 | 判断是否过度拥挤 |
| 资金流 | 公募发行、ETF 申赎、北向/南向、产业资本 | 判断增量资金 |
| 政策/事件 | 产业政策、监管、外部冲击 | 判断风险偏好变化 |

## 拥挤度的六个指标

1. 公募基金前十大重仓是否过度集中。
2. 该股/该板块在主动权益基金中的持仓比例。
3. 换手率是否处于历史高位。
4. 融资余额是否快速上升。
5. 分析师覆盖与目标价是否一致乐观。
6. 近期是否出现「业绩超预期但股价不涨」。

第 6 条是典型的「预期打满」信号。

## 四种市场环境

| 环境 | 特征 | 对成长股 | 动作 |
|---|---|---|---|
| 主升/景气上行 | 龙头持续新高、板块批量超预期、资金流入 | 最友好 | 持有核心 α；回调分批 |
| 高位拥挤 | 龙头滞涨、二线补涨、换手高、基金集中 | 波动放大 | 不追高；降仓位；等出清 |
| 风格切换 | 资金流向红利/价值，成长杀估值 | 逆风 | 等新主线或新新高，不抄底 |
| 熊市/反弹浪 | 低点下移、反弹失败、成交萎缩 | 最难 | 只做反弹，不重仓；等趋势反转 |

## 与太极两仪体系的关系

- 作者强调「只跟随，不预判」：市场环境是「看见」的一部分，不是预测。
- 作者也强调「万物皆周期」：拥挤的高景气也会大跌，业绩好不等于不跌。
- 「市场永远比基本面快一步」：基本面还在，股价可能先跌；不要用基本面安慰自己，也不要用股价否定基本面。
- 市场环境差时，六条标准仍然有效，但**买点要更苛刻**。

## 输出方式

```text
市场环境：主升 / 高位拥挤 / 风格切换 / 熊市反弹
证据：指数位置、风格、拥挤度、资金流、政策
对个股的影响：只影响节奏与仓位，不改变公司质量判断
动作：等新高 / 等出清 / 只跟踪 / 不参与
```

## 禁止事项

- 不用「大盘要涨/要跌」替代个股研究。
- 不用宏观预测直接推导个股买卖。
- 不把「跌了很多」当成「风险释放完毕」。
- 不把「业绩好」当成「不会下跌」。
- 不把「拥挤」当成「不能涨」，只当成「赔率下降」。
