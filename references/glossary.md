# 术语表

| 术语 | 在本体系中的含义 |
|---|---|
| α（阿尔法） | 景气行业里最核心受益、市场认可的龙头标的；不是泛指超额收益 |
| β（贝塔） | 行业或市场整体的趋势性力量 |
| 超级成长股 | 业绩、规模、市场空间高速扩张，作者认为具备 10 倍潜力的公司 |
| 景气度 | 行业供需、价格、订单、业绩增速的综合状态 |
| 拐点 | 景气由上行转下行或由下行转上行的确认点，不靠猜 |
| 供不应求 | 需求大于供给，表现为产线满产、下游排队、接受高溢价 |
| 量价齐升 | 销量与价格同时上升，通常伴随毛利率改善 |
| 戴维斯双击 | 业绩增长与估值提升同时发生 |
| 持盈止损 | 盈利侧拿住，亏损侧看错就砍；不是按固定百分比止盈止损 |
| 拥挤度 | 板块内资金与筹码的集中程度；高景气也可能因拥挤而大跌 |
| 比较优势 | 只跟已经走出来的最强趋势，不博弈盘整尾部的弱势股 |
| 后排受益期 | 二线公司开始持续超预期、一线龙头涨不动，常被视为产业后段信号 |
| 姚明性机会 | 一眼能看出「最高」的机会，胜率与赔率双高、无需复杂论证 |
| 产业对标 | 看海外巨头 all in 什么，找中国产业链中不可替代的环节 |
| 反者道之动 | 作者的行为原则：在关键决策上与小散群体反向 |
| 定量分析 | 对过去的数字化总结，可筛选、可复核 |
| 定性分析 | 对未来商业持续性、竞争格局的判断，依赖经验，无法完全外包 |
| 比较分析 | 多只合格标的中横向选出持续性最强、确定性最高者 |
| 高切低 | 卖掉高位强势股、买低位弱势股；作者认为是伪命题 |
| 做 T | 日内高抛低吸；作者强烈反对 |
| 缠论 | 一种技术分析理论；作者强烈反对作为投资核心 |
| 两仪 | 本 skill 的组织框架：阴仪看公司质量与估值，阳仪看行业景气、趋势与资金 |
| 四象 | 本 skill 的研究四象限：共振、左侧、主题、退潮；不是买卖信号 |
| 听劲 | 观察市场对财报、利空、突破和资金流的反馈，只作阳仪辅助证据 |
| 守中 | 执行纪律：不加杠杆、不单吊、不用摊平替代证伪；不是中性态度 |

遇到作者的黑话（a5/a7/a8/a9/a10）时，可解释为资金量级，但不要把它当成投资能力的证明。
