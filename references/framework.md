# 体系总览

## 这套体系在回答什么

本框架不是「如何预测大盘」，而是：

> 找到当下时代最景气行业中，核心受益且市场认可的超级成长股（α）；等回调分仓分批介入；对了死拿，错了砍掉。

它把投资拆成一条链：

`时代景气 → 行业 β → 核心 α → 标的资质 → 买入节奏 → 持有/退出纪律 → 仓位风控`

任何一环缺失，后面的结论都不成立。不要用「好行业」替代「好公司」，也不要用「好公司」替代「好价格与好节奏」。

## 太极两仪的读法

本 skill 把上面的链条压成两仪：

- **阴仪**回答“公司本身值不值得研究”：业绩、现金流、竞争格局、估值与管理层。
- **阳仪**回答“市场是否已经认可”：行业景气、价格趋势、资金、板块效应与拥挤度。

阴仪强、阳仪弱，是基本面候选；阳仪强、阴仪弱，是主题或资金行情；两者都强才是共振，但仍需过六条标准与估值关。两仪是证据分类，不是玄学，也不是买卖信号。

完整的四象、听劲与守中方法见 `taiji-method.md`。

## 十条底层原则

1. **买股票就是买公司**：赚企业成长的钱，不赚筹码博弈的钱。要 10 倍，先找业务体量能增长 10 倍的公司。
2. **极简专注**：不买垃圾股；一般机会不参与。把精力集中在少数超级成长股上。
3. **大机会驱动**：财富跃迁靠少数大机会，不靠每年稳定 20% 的小步积累；平时研究、等待，机会来时重仓（在风控允许范围内）参与。
4. **万物皆周期**：没有永远上涨的赛道；但周期有拐点，拐点未出现时，低位不等于机会。
5. **拐点靠确认，不靠猜**：跟踪产业趋势、公司交流、调研纪要、研报与财报；拐点出现时，财报数据会清晰展现。
6. **两种价值投资不可混用**：长线股权价投看垄断性、定价权、持续性；景气成长价投看宏观稳定性、行业天花板、业绩增速确定性。作者主做后者。
7. **价值投资有三道门槛**：确认优质资产、科学估值、持续跟踪并捕捉拐点。三者都难，不要把它简化成「长期持有」。
8. **反者道之动**：作者主张在关键行为上与小散反向——恐低不恐高、买强不买弱、浮盈加仓而非越跌摊平、错了割肉而非死扛。
9. **散户的优势是快，不是聪明**：作者认为散户从发现到行动可比机构快 3–6 个月；但标的仍要符合机构偏好，因为大资金最终会来「抬轿」。
10. **好机会稀少且显见**：真正的大机会往往一眼能看出「它最高」，不需要反复论证；需要复杂论证才勉强成立的机会，大概率不是。

## 价值投资的双轨

| 路径 | 核心三点 | 适用 |
|---|---|---|
| 长线股权价投 | 垄断性、定价权、持续性 | 超大资金、超长线；作者称 A 股满足者极少 |
| 景气成长价投 | 宏观经济稳定性、行业天花板、业绩增速确定性 | 作者主做；中长线超级成长股 |

把两套标准混用，容易出现「用长线价投的名义，买景气下行的成长股」这类伪价投。

## 投资模式五分法

| 模式 | 核心 | 作者态度 |
|---|---|---|
| 短线题材 | 游资、情绪、筹码 | 波动大，走出来者少 |
| 短线技术分析 | 缠论、波浪、K 线、筹码 | 赚小钱易、赚大钱难，作者强烈反对 |
| 中线成长价投 | 产业趋势 + 超级成长 | **作者主做** |
| 长线股权红利 | 高股息、公用事业、银行 | 适合不研究或高龄投资者；熊市抗跌、牛市跑输 |
| 长线股权垄断 | 品牌、定价权、奢侈属性 | 超长线，标的稀缺 |

## 「与小散反着来」对照

这是作者 2026-09-15 的版本，属于**行为原则**，不是市场预测：

| 小散常见做法 | 作者主张 |
|---|---|
| 买低位垃圾股 | 跟踪高位绩优股 |
| 恐高 | 恐低 |
| 不看财报、不投研 | 财报季认真跟财报 |
| 情绪化、冲动交易 | 按体系执行 |
| 下跌补仓摊平 | 下跌先判断是否错了；错了割肉 |
| 梭哈单吊 | 分仓分批，浮盈加仓 |
| 拒绝学习 | 持续提高认知 |
| 买弱势股 | 只买超级强势股 |
| 博弈反转 | 买强者恒强 |
| 没耐心、赚小钱就跑 | 看对大机会就拿住 |
| 怕浮盈回吐 | 怕浮亏扩大，错了认错 |

注意：这张表是作者对「散户群体行为」的概括，不是对每个投资者的道德评判；不要用它替代具体证据。

## 定量、定性、比较

作者把选股分析分成三层：

1. **定量**：增速、亏损、供需、股价位置等可量化门槛；可被 checklist 和脚本辅助。
2. **定性**：商业模式、竞争格局、成长持续性、管理层与产业理解；依赖个人经验，无法完全外包。
3. **比较**：同一时段多只合格标的里，选持续性最强、确定性最高的那一两只。

本 skill 主要辅助「定量筛选」和「结构化比较」，不能替代定性判断。作者本人也明确说过：定量可以趋同，定性无法传授。

## 作者自述的局限

- 案例是后视镜，存在幸存者偏差；同一标准筛出的失败者没有被记录。
- 「创新高」「强者恒强」依赖特定流动性环境，不是永恒规律。
- 「敢全身价压上」是筛选问题，不是仓位建议；执行层仍是分仓、不杠杆、不单吊。
- 对技术分析、短线、MBTI、财富路径的判断带有强烈个人色彩，应作为观点而非事实。

完整批判见 `source-provenance.md`。

## 好公司 / 好股票 / 好买点

三者必须分开：

- **好公司**：生意质量、增长可持续性、现金流、竞争格局。
- **好股票**：市场认可、趋势向上、持续新高、板块效应。
- **好买点**：在好公司 + 好股票的前提下，估值与赔率仍然合适。

好公司可能长期不是好股票；好股票可能在任何价格都不是好买点。这个区分见 `valuation-expectations.md`。
