# 数据协议

## 目的

解决「目前哪些公司满足条件」这类问题。没有数据协议，模型容易把历史案例当当前事实，或者用不同口径混着比较。

## 先问四个问题

1. **市场**：A 股 / 港股 / 美股？
2. **股票池**：全市场、某个行业，还是指定 3–10 家公司？
3. **数据截止日**：`as_of_date` 是哪一天？
4. **数据来源**：用户提供的 CSV/Excel、公司公告、交易所、Choice/同花顺/Wind 导出，还是公开网页？

四个问题缺一个，就先输出「数据缺口卡」，不要直接给名单。

## 最小数据卡

| 字段 | 说明 |
|---|---|
| `as_of_date` | 分析截止日，必须写 |
| `market` | A 股 / 港股 / 美股 |
| `stock_pool` | 筛选范围 |
| `source` | 数据来源与链接/文件名 |
| `period` | 单季 / 累计 / TTM |
| `price_adjustment` | 前复权 / 不复权 |
| `currency` | 人民币 / 港币 / 美元 |

## 公司层字段

| 类别 | 字段 |
|---|---|
| 增长 | 营收增速、归母增速、扣非增速、单季营收/利润增速 |
| 质量 | 毛利率、净利率、经营现金流、应收账款、存货、非经常性损益、公允价值变动、并表 |
| 供需 | 在手订单、产能利用率、交期、价格、客户集中度 |
| 市场 | 股价、52 周高点、距高点幅度、市值、PE TTM、2026/2027 一致预期、公募持仓、换手率 |
| 管理层 | 增持、回购、股权激励、业绩承诺 |

## 板块层字段

判断“板块是否处于上行期”时，至少拉齐以下字段：

| 类别 | 字段 |
|---|---|
| 行业口径 | 申万/中信/东财行业名称、成分股数量、调整日期 |
| 景气 | 营收增速、利润增速、Q3 单季增速、订单/价格/产能、业绩上修/下修 |
| 价格 | 年内涨幅、20/60 日涨幅、距 52 周高点、是否新高、相对沪深 300 强弱 |
| 资金 | 主力净流入、ETF 份额、北向/南向、公募持仓、成交额/换手率 |
| 广度 | 上涨家数、创新高家数、龙头/二线相对强弱、拥挤度 |
| 估值 | PE/PB 历史分位、2026E/2027E 一致预期、预测区间 |

板块结论必须写成：

```text
阴仪：景气/盈利（强/中/弱/缺口）
阳仪：价格/资金（强/中/弱/缺口）
四象：共振/左侧/主题/退潮
```

单日涨幅只能作为阳仪的一个观察点，不能单独定义“上行期”。

## 来源优先级

1. 用户提供的原始数据文件。
2. 公司公告、财报、招股书、交易所披露。
3. 券商研报与一致预期（注明机构与日期）。
4. 主流财经媒体（注明链接与日期）。
5. 论坛/自媒体只作线索，不作事实依据。

为与 `analysis-blocks.md` 统一，输出时用 S1–S5 标注：S1 公告/财报/交易所，S2 公司 IR/官网，S3 政府/协会/数据库，S4 券商研报/媒体，S5 论坛/自媒体；用户提供的原始文件按其原始来源定级。

## 处理规则

- **没有数据**：写 `缺口`，不要用「大概」「应该」补。
- **口径统一**：同一张表里不要混用单季与累计、营收与扣非。
- **价格口径**：创新高、回撤必须说明前复权/不复权。
- **并表/重组**：标 `并表驱动`，优先用可比口径或 pro forma。
- **非经常/公允价值**：标 `非经常驱动` / `账面利润`，同时看扣非与主业。
- **周期涨价**：拆量、价、毛利率；不要把涨价周期当成永久成长。
- **来源标注**：每个关键数字带来源与日期；无法核验的写 `未核验`。

## 使用筛选脚本

用户提供 CSV/Excel 后，可运行：

```bash
python scripts/screen.py --input tests/sample-screen.csv --format markdown
```

脚本只做确定性初筛，不联网、不构成投资建议。字段缺失会输出「缺口」，不会自动补全。

## 数据请求模板

```text
市场：
股票池：
数据截止日：
数据来源/文件：
期间口径：单季 / 累计 / TTM
价格口径：前复权 / 不复权
希望筛选的条件：六条标准 / 仅增速 / 行业对比
```

## 禁止事项

- 用 2026 中报数据回答「2026 年 11 月目前」的问题。
- 用不复权高点计算回撤。
- 用归母净利高增替代营收/主营增长。
- 把并表、低基数、非经常性收益、公允价值变动当成内生成长。
- 把作者的历史案例当成当前候选名单。
