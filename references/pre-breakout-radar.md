# 爆发前雷达：第二级火箭研究法

> 用途：在产业趋势确认但市场尚未定价的窗口期（新业务有真实订单、收入占比仍低），识别"爆发前"的成长股候选。本方法与六条标准互补：六条标准筛"第三级火箭"（太阳·共振），本方法找"第二级火箭"（少阴·主题向少阳·左侧迁移前夜）。

## 一、三级火箭模型

一只股票从无人问津到超级成长股要经过三级火箭：

```text
第一级：政策/技术拐点出现（无业绩，只有逻辑）→ 少阴·主题（胜率最低）
第二级：第一批 L1 订单/产能落地（新业务收入占比 < 10%）→ 少阴 → 少阳过渡（本方法战场）
第三级：收入占比 > 10% + 股价创新高 + 板块效应 → 太阳·共振（六条标准战场）
```

第一级太早（纯讲故事，胜率极低），第三级已被市场定价。**只有第二级——有真实订单但市场还没定价——是赔率与确定性的最优交点。**

## 二、四项先行指标

对每个候选方向/标的逐项判定，四项全中 = 点火信号；三项 = 重点研究；两项以下 = 观察或淘汰。

### 指标一：在手订单增速 > 营收增速（阴仪）

订单先于收入确认。财报附注里的合同负债、存货、预收款是收入的领先指标。

- **怎么查**：合同负债环比/同比；在手订单披露；存货中发出商品/在产品占比上升（备产信号）。
- **命中**：订单增速 > 营收增速，且订单为 L1 级（正式合同/中标/有金额和交付条款）。
- **未命中**：订单增速 ≤ 营收增速，或订单仅为 L2–L4 级（战略协议/意向/送样）。

### 指标二：新业务收入占比向 10% 爬坡（阴仪）

占比 < 5% = 纯故事；5%–10% = 起量前夜（最优窗口）；> 10% = 第二曲线成立中；> 30% 且总营收恢复增长 = 换挡成功（进入第三级，不再是本方法战场）。

- **怎么查**：财报分部/分产品收入拆解；业绩说明会披露；产业链数据（单机价值量 × 客户出货量，标注推断）。
- **命中**：占比在 5%–10% 区间且环比/同比在爬坡。
- **未命中**：占比 < 5% 或 > 30%（前者太早，后者已被定价）。

### 指标三：产能与新产能建设同步启动（公司行为）

供给端先行 = 公司自己在赌订单落地。产能利用率高企 + 在建工程增速上行 = 公司内部订单能见度的外化。

- **怎么查**：在建工程增速；募投/定增/可转债扩产用途；交付周期（变长 = 供不应求）。
- **命中**：在建工程增速显著高于营收增速，或交付周期在拉长。
- **未命中**：产能利用率低且无扩产计划，或扩产远落后于订单节奏。

### 指标四：板块内部非主流标的批量创新高（阳仪）

资金从一线溢出到二线 = 阳仪即将确认的前兆。

- **怎么查**：板块内年内创一年新高家数；二线相对一线的相对强度变化；融资余额/ETF 份额增量。
- **命中**：板块内 ≥ 3 只非一线标的批量接近/创一年新高。
- **未命中**：只有一线龙头涨，或板块整体阴跌。

**使用规则**：前三项成立、第四项未成立 = 最优的"爆发前"窗口（阳仪还没来，赔率最高）。每项判定写命中/未命中/缺口，缺口就是下一步要读的具体公告/财报。

## 三、输出格式：雷达地图

先写数据边界：`as_of_date / 市场 / 股票池 / 来源 / 未核验项`。

| 梯队 | 方向/标的 | 当前证据（含订单约束力等级） | 爆发信号 | 证伪信号 | 四指标命中数 |
|---|---|---|---|---|---|

- **第一梯队**：已有 L1 正式订单 + 新业务收入占比 < 10%，四指标 ≥ 3 项。核心战场，写明跟踪的公告/财报项。
- **第二梯队**：技术路线已定 + 商业化还早（L2–L3 协议或示范项目），四指标 ≤ 2 项。期权观察，写明关键跟踪节点。
- **第三梯队**：纯主题/技术路线未定/无商业化收入。不进雷达正文，单列"只观察，不建仓逻辑"。

**信号写法**：爆发信号与证伪信号都必须具体可验证（"2027Q2 财报新业务占比 ≥ 10%"是合格写法，"行业景气提升"不是）。

## 四、硬规则

- 不荐股、不给买卖点、目标价、仓位比例；输出永远是研究雷达。
- 订单按 `analysis-blocks.md` 的 L1–L4 分级，L2 以下不得写成"已获订单"。
- 新业务占比 < 10% 不得称第二曲线已兑现；10%–30% 写"成立中"；> 30% 且总营收恢复增长才写"换挡成功"。
- 每个候选必须同时写升级信号和证伪信号，缺一个就不是合格输出。
- 跟踪只盯两个数字：**新业务收入占比、在手订单增速**。前者过 10% 是升级信号，后者掉头是证伪信号。
- 历史案例（如 2020 年宁德、2023 年光模块）只作方法演示，标注"历史举例"。
