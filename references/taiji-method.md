# 太极两仪方法

## 定位

“太极两仪”是本 skill 的组织与输出框架，不是原始作者的原话，也不是玄学预测工具。

它只做三件事：

1. 把公司证据（阴）和市场证据（阳）分开，防止用故事替代数据；
2. 把标的或板块放入四象限，防止把反弹当趋势、把便宜当买点；
3. 用“守中”约束仓位与复盘，防止判断正确但执行失控。

所有判断仍要回到可核验事实。没有数据就写 `缺口`。

## 一、两仪

| 仪 | 核心问题 | 证据 |
|---|---|---|
| **阴仪** | 这是不是一家好公司？增长是否真实、可持续、可估值？ | 营收/利润/扣非、单季与累计、毛利率、经营现金流、应收/存货、订单、产能、竞争格局、估值、管理层 |
| **阳仪** | 市场是否认可？行业是否在景气上行？价格与资金是否形成趋势？ | 行业价格/销量、供需、政策、股价相对强度、52 周新高、成交/换手、资金流、板块效应、拥挤度 |

### 阴仪判定

按顺序问：

1. 是否亏损？亏损直接降档。
2. 营收、利润、扣非是否达到用户采用的增速门槛？默认是 40%。
3. 高增长来自内生放量、新产品、新市场，还是并表、低基数、非经常、公允价值、周期涨价？
4. 毛利率、现金流、应收、存货是否支持利润质量？
5. 当前利润是常态、周期高点，还是低基数修复？
6. 当前估值隐含了什么增长预期？低 PE 是否可能是峰值利润陷阱？

阴仪的结论只能是：

- `强`：增长与质量同时成立；
- `中`：增长成立但质量或持续性有瑕疵；
- `弱`：增速不足、亏损、现金流恶化或估值透支；
- `缺口`：没有足够数据。

### 阳仪判定

按顺序问：

1. 行业处于导入、成长、成熟、周期底部，还是后排受益期？
2. 价格、销量、订单、交期、政策是否同向改善？
3. 股价是创新高、接近新高、震荡，还是下跌趋势？
4. 资金是持续流入，还是单日脉冲？板块是普涨还是只有少数龙头？
5. 拥挤度是否已经过高？业绩超预期但股价不涨，是否已经 price in？

阳仪的结论只能是：

- `强`：中期趋势向上，接近/创 52 周新高，资金有持续性；
- `中`：基本面强但价格未确认，或价格强但基本面待验证；
- `弱`：价格下行、资金流出或拥挤度反转；
- `缺口`：没有行情、资金或行业数据。

### 两仪合参

| 阴仪 | 阳仪 | 判断 |
|---|---|---|
| 强 | 强 | 重点研究；仍需过六条标准，不追高 |
| 强 | 中/弱 | 基本面候选，等价格确认；不把“跌多了”当买点 |
| 中/弱 | 强 | 主题或资金行情；防拥挤、防业绩证伪 |
| 弱 | 弱 | 退潮或下行；等待，不抄底 |
| 缺口 | 任意 | 先补数据，不形成结论 |

## 二、四象

“四象”在这里是四象限的操作命名，不作术数推断。

| 四象 | 阴仪 | 阳仪 | 研究动作 |
|---|---|---|---|
| **太阳 · 共振** | 上行 | 上行 | 进入核心研究池；核对六条标准、估值与反例 |
| **少阳 · 左侧** | 上行 | 未确认 | 跟踪财报、订单、价格；等趋势修复，不预测底部 |
| **少阴 · 主题** | 未确认/下行 | 上行 | 只按主题或反弹研究；不当中线成长 |
| **太阴 · 退潮** | 下行 | 下行 | 等待或回避；不因跌幅大而抄底 |

四象不是买卖信号。它只回答“先研究谁、先放弃谁、还缺什么证据”。

### 板块“上行期”的判定

一个板块只有在以下三项中至少两项成立，才可以称为“相对上行期”：

1. **景气上行**：营收/利润/订单/价格至少两项改善；
2. **价格上行**：中期相对强度为正，接近或创 52 周新高；
3. **资金上行**：资金持续净流入，板块内部有广度。

三项同时成立，才是“共振”。只有业绩没有价格，是左侧；只有价格没有业绩，是主题；三者都没有，是退潮。

输出时必须写清：

- `as_of_date`
- 行业分类口径（申万/中信/东财等）
- 价格口径（前复权/不复权）
- 资金口径（主力/北向/ETF/公募）
- 数据来源与缺口

## 三、听劲

“听劲”不是猜涨跌，而是看市场对事实的反应。

重点听四种劲：

1. **财报后的反应**：业绩超预期但股价不涨，说明预期更高或筹码更重；
2. **利空后的反应**：利空不跌，说明卖压可能已经释放；
3. **板块内部广度**：只有龙头涨，还是二线跟上？后者常见于产业后段；
4. **量价与资金**：突破是否有量，回撤是否缩量，资金是否连续。

听劲只做阳仪的辅助证据，不能替代基本面。不能因为“感觉主力在吸筹”就给出结论。

## 四、守中

“守中”是执行纪律，不是中性态度。

- 不加杠杆；
- 不单吊；
- 不因浮盈/浮亏改变原判断；
- 不用下跌摊平替代证伪；
- 不用“长期看好”掩盖景气拐点；
- 逻辑破坏时先退出，再复盘；
- 仓位上限与单只上限由用户自己定义，本 skill 不给具体比例。

守中的目的不是“永远正确”，而是让错误可承受、让正确能持有。

## 五、输出格式

做公司或板块研究时，默认输出：

```markdown

## 两仪定位
| 仪 | 判定 | 证据 | 依据层级 |
|---|---|---|---|
| 阴仪 | 强/中/弱/缺口 | | |
| 阳仪 | 强/中/弱/缺口 | | |

## 四象定位
太阳·共振 / 少阳·左侧 / 少阴·主题 / 太阴·退潮 / 不适用

## 框架判断
好公司 / 好股票 / 好买点；或够格 / 不够格 / 证据不足

## 六条标准
| 维度 | 判定 | 证据 | 依据层级 |
|---|---|---|---|

## 反例与缺口
- 什么证据会推翻当前判断：
- 还缺什么数据：

## 下一步
- 读哪份公告/财报：
- 跟哪个价格/景气/资金信号：
```

## 六、禁止事项

- 把“太极两仪”写成玄学、命理或神秘预测；
- 用“主力”“庄家”“气数”替代可核验证据；
- 用四象直接给出买入/卖出结论；
- 把阴仪强当成好买点，把阳仪强当成好公司；
- 用单日涨幅定义板块上行期；
- 用历史案例冒充当前事实；
- 给出目标价、买卖点或仓位比例。
