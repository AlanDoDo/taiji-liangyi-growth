# 估值与预期

## 三个概念必须分开

| 概念 | 问题 | 判断依据 |
|---|---|---|
| 好公司 | 生意好不好、增长能不能持续 | 增速、毛利率、现金流、订单、竞争格局 |
| 好股票 | 市场认不认可、趋势在不在 | 股价位置、52 周新高、板块效应、资金 |
| 好买点 | 现在买赔率划不划算 | 估值、隐含预期、回撤、拥挤度、证伪条件 |

**好公司不等于好股票；好股票不等于任何价格都是好买点。**

## 估值的最小工具

### 1. 市值与 PE

```text
市值 = 股价 × 总股本
PE(TTM) = 市值 / 最近四个季度归母净利
Forward PE = 市值 / 未来一年一致预期净利
```

必须写清：`as_of_date`、股价口径（前复权/不复权）、净利口径（归母/扣非/经调整）。

### 2. 一致预期与分歧

至少收集：

- 2026E / 2027E 净利均值；
- 预测区间（最低/最高）；
- 覆盖机构数量；
- 最近一次上修/下修方向。

一致预期区间越宽，说明分歧越大，低 PE 的「便宜」越不可靠。

### 3. 隐含增长

用简化 PEG 或情景法回答：

```text
PEG = PE / 预期净利增速
```

PEG 只能作粗略参考，不能替代现金流/竞争格局判断。

### 4. 峰值利润陷阱

**低 PE 可能是因为市场不信这是可持续利润。**

周期股、涨价链、AI 硬件在景气高点常见：

- 当年 PE 很低；
- 下一年利润可能大幅下滑；
- 股价先跌，估值反而「看起来便宜」。

必须问：当前利润是常态、周期高点，还是低基数修复？

### 5. 估值桥（反推）

高估值不能只说「贵」，要反推当前市值隐含了什么：

```text
当前市值 ÷ 目标 PE = 需要的净利
需要的净利 ÷ 净利率 = 需要的收入
需要的收入 ÷ 当前收入 = 需要的收入倍数
```

亏损公司改用 `市值 ÷ 目标 PS = 需要的收入`。输出的是情景假设，不是目标价；必须写清收入、净利率、目标 PE、时间窗口和证伪条件。完整模板见 `analysis-blocks.md` 的估值桥块。

## 三情景表

每家公司至少做三个情景：

| 情景 | 2027E 净利 | 隐含 PE | 触发条件 | 证伪信号 |
|---|---|---|---|---|
| 乐观 | | | 订单/渗透率/份额超预期 | |
| 中性 | | | 当前一致预期 | |
| 悲观 | | | 需求放缓/价格战/替代 | |

输出时不要给目标价，只给「在什么利润假设下，当前市值对应多少 PE」。

## 中际旭创案例（仅作方法演示；数据截至 2026-11-13）

```text
2026-06-22 前复权高点 1416.88；2026-11-13 收 477.30，回撤约 66%
2026E 一致净利 339.68 亿；2027E 一致净利 670.89 亿（区间 465–892 亿）
当前市值约 5,323 亿

2026E PE ≈ 15.7x
2027E PE ≈ 7.9x（按均值）
若 2027 净利 350 亿 → PE ≈ 15.2x
若 2027 净利 250 亿 → PE ≈ 21.3x
```

结论不是「便宜」或「贵」，而是：

- 若 2027 一致预期成立，当前估值很低；
- 若市场担心 AI capex 见顶、CPO 替代、价格战，低 PE 可能是峰值利润陷阱；
- 股价从高点回撤 66%，说明市场在重新定价「成长久期」，不是简单杀业绩。

## 输出规则

- 不给目标价、不给买卖点。
- 不把「低 PE」直接等同于「便宜」。
- 不把「高 PE」直接等同于「泡沫」。
- 一致预期缺失时写 `缺口`，不要自己编 2027 利润。
- 估值只回答赔率，不替代公司质量与趋势判断。
- 股价位置必须单独写：是否创新高、距 52 周高点多少、年内涨跌。

## 快速检查清单

1. 当前 PE TTM 是多少？用什么净利口径？
2. 2026E/2027E 一致预期是多少？区间多宽？
3. 当前市值隐含的 2027 PE 是多少？
4. 如果 2027 利润低于预期 30%，PE 会变成多少？
5. 当前利润是常态、周期高点，还是低基数修复？
6. 股价是否创新高？回撤多少？趋势向上还是向下？
7. 低 PE 是市场错杀，还是市场在提前定价衰退？
