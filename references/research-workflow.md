# 投研流程与日常功课

## 财报季：只是一个窗口，不是全部

作者把一年分成四个财报季：1 月、4 月、7–8 月、10 月。核心动作：

- 密集读业绩大增公司的财报、招股书、调研纪要。
- 找当季新出现的超级成长股。
- 用财报验证「增速还在不在」。

但本 skill 不以财报分析为主轴。财报的作用是：

1. 验证六条标准中的增速、供需、新品兑现；
2. 排除低基数、并表、涨价水分；
3. 发现「业绩超预期但股价不涨」的兑现风险。

用户若要做完整财务建模、估值或科目拆解，应转用专门的财报/估值工具。

## 每日功课

作者的习惯，作为参考而非硬性要求：

1. 读财报：财报季高强度；平时每天一份。
2. 看新闻：政策、产业、宏观、周期拐点。
3. 建档案：持续跟踪的标的建立材料夹，更新基本面。
4. 写笔记：记录灵感、判断、复盘与反省。
5. 用投资视角看世界：新产品、新服务、新业态、新市场。
6. 刷信息源：研报、公众号、行业交流；先初筛，再深研。
7. 不依赖 AI 总结：作者认为 AI 只能辅助，不能替代亲自读财报与跟产业。

## 刻意观察法

适合普通人的消费股线索：

- 在日常工作、逛街、旅行、网购、刷视频时，留意「过去没有、当下突然爆火、快速普及」的产品。
- 找到上市公司母公司，再验证：
  - 是否真的放量，不是短期网红；
  - 门店/用户/复购/供应链是否支持扩张；
  - 财报是否体现收入、利润、现金流；
  - 竞争格局是否允许持续。
- 看到排队、爆火、断货，只是线索，不是买入理由。

## 历史牛股复盘

作者认为这是进步最快的方法：

1. 选一只历史超级成长股。
2. 把当年的行业背景、财报、调研纪要、研报、公告与股价阶段对齐。
3. 问：
   - 当时能看到什么证据？
   - 哪些是事后才知道的？
   - 什么信号会证伪它？
   - 同期被淘汰的同行是什么样？
4. 输出「当时可见 / 事后归因 / 可迁移规则 / 不可迁移运气」四栏。

不要只复盘赢家；失败者和同行对比，才能校正幸存者偏差。

## 检索—识别—跟上

作者 2026-09-12 的三能力：

1. **检索**：在全市场里找到少数候选；靠勤奋、筛选和精力管理。
2. **识别**：通过复盘历史公司与读财报，形成「好公司」的定性标准；换一个行业也能认出来。
3. **跟上**：大机会不会一天结束；发现时可能已经涨了很多，需要克服恐高，按纪律参与。

本 skill 主要辅助「检索」和「识别」的结构化部分；「跟上」的勇气与定性判断不能外包。

## 定量、定性、比较

| 层级 | 内容 | 本 skill 能做什么 |
|---|---|---|
| 定量 | 增速、亏损、供需、股价位置、估值 | 清单、阈值、证据核对 |
| 定性 | 商业模式、竞争格局、持续性、管理层 | 提问、反例、待验证项 |
| 比较 | 多只合格标的里选最优 | 并排对照、指出差异 |

作者明确说过：定量可以趋同，定性无法传授。不要把本 skill 的输出当成最终选股结论。

作者的分级书单只作为参考，不强制执行：

- 入门：《小狗钱钱》《穷爸爸富爸爸》

作者强烈反对技术分析、筹码分析、跟庄、短线类书籍；这是他的个人观点，不是绝对禁令。
